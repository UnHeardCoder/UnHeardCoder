## What I'm Building
 
### 🖥️ [Cubelit](https://github.com/UnHeardCoder/cubelit)
 
> A desktop app that turns Docker containers into one-click game servers — no command line needed.
 
Pick a game, configure it through a visual wizard, and hit create. Cubelit handles the image pull, container setup, port mapping, and volume management behind the scenes. Built with a **Rust** backend via Tauri and a **Svelte 5** frontend.
 
**Supports:** Minecraft Java, FiveM, and 8 more games on the way.
